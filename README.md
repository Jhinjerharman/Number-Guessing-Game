# 🎯 Number Guessing Game (Python)

A simple and interactive **Number Guessing Game** built using Python.  
This project is designed for beginners to practice core programming concepts like loops, conditions, and user input.

---

## 📖 About the Project

In this game, the computer randomly selects a number within a given range, and the player has to guess it.

After each guess, the program provides feedback:
- 📉 If the guess is too low
- 📈 If the guess is too high  
- 🎉 If the guess is correct

The game continues until the correct number is guessed.

---

## 🧠 Concepts Covered

This project helps you understand:

- `while` loops  
- `if-elif-else` conditions  
- Random number generation using `random` module  
- Taking user input using `input()`  
- Basic program flow control
